# COREXION website (corexion.uk)

Static site served by nginx on Railway (Dockerfile in this folder). All files are in one flat folder.

Pages: index, who-we-are, services, projects, sectors, insights, article-*, contact, privacy, cookies, 404.
m.css / m.js add the mobile layout (menu and single-column layout under 820px).
The contact form opens the visitor's email app with the enquiry addressed to info@corexion.uk.
